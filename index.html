How it works

Duplicate detection ▸

Sift compares a tab's URL, title, and page content — so it catches copies even when one has been sitting idle, or you've been logged out of the page.

Smart grouping ▸

Tabs with related content are grouped automatically. Groups are color-coded and collapsible, so a dozen tabs on one topic take up the space of one.

Usage-based archiving ▸

Sift watches when a tab was last opened, for how long, and how often. Ones that have gone quiet are flagged to archive — never deleted outright.

Pattern learning ▸

Sift notices which tabs you tend to open together and starts grouping them on its own. The longer you use it, the more it fits how you actually work.

Every tab is an unfinished task

Closing one feels like quitting

Tabs stand in for pending work. Closing them reads as giving up on the task, so people keep dozens open just as a reminder that it isn't done yet.

You can only track about seven at once

Working memory holds roughly four to seven items. Past that count, you lose track of what's already open — and open the same page again.

More tabs, less speed

Every open tab holds memory. More memory used means a slower machine — and a slower you.
